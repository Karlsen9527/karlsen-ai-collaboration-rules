# 工具接入约定

本版只有文档约定和薄加载入口，未实现自动拉取、后台同步、哈希校验程序或全客户端部署。

每个工具接入时需记录客户端及版本、支持的入口、读取权限、可信发布源、approved 证据验证方法、缓存位置和测试结果。记录中不得含凭据、个人审批原文或私人任务信息。

## 目标行为

1. 及时响应用户；正式处理前查询可信发布源。
2. 将 manifest 和 core/PROTOCOL.md 固定在同一不可变提交读取。
3. 校验 protocol_id、version、status、原始字节 SHA-256，以及经过认证渠道的批准引用。不能只相信仓库文字。
4. 每次实际处理在自己的任务上下文记录版本、提交与正文哈希；仅加载指定项目。
5. 发布无变化时复用已校验缓存。查询失败时明确标注“最后已核验版本，未证明最新”，并处理撤销和权限不确定性。
6. 新版本先做影响评估；原审批范围不自动扩大。
