# 工具接入约定

本版只有文档约定和薄加载入口，未实现自动拉取、后台同步、哈希校验程序或全客户端部署。

每个工具接入时需记录客户端及版本、支持的入口、读取权限、可信发布源、approved 证据验证方法、缓存位置和测试结果。记录中不得含凭据、个人审批原文或私人任务信息。

## 当前适用范围

core 8.0.0 只约束用户与主助手的沟通和任务组织。担任任务执行者的模型或工具默认不加载、维护 core，不承担聊天菜单；按完整任务路线、项目明确约束与环境安全权限规则执行。入口文件发布不证明旧绑定已解除或业务项目已迁移。

## 公开读取、角色与能力边界

固定提交正文可匿名读取，无需登录 GitHub；客户端仍可能有自身联网限制。main 可用于发现内容，实际引用须解析为固定提交；已有项目 pin 不自动升级。不能联网时可读取用户提供的完整固定内容，但须说明未独立取回来源；页面摘录或转换文本不等于原始字节，只有文本能力时不得声称机器核验了哈希。具备联网读取、原始文件计算或执行工具时，只报告实际完成的相应检查；无后台能力时不得承诺定时主动回报。缺少必需能力时说明未完成项、所需能力及下一责任方，不假定所有模型都能调用终端、多代理或后台任务。

主助手与执行者是当前任务角色，同一模型可以切换角色，不由品牌或名称决定；本规范不要求安装 Codex、DSH 或专属客户端，也不覆盖平台、环境和工具的更高优先级规则。专属适配仅对实际选用的工具有效。

外部使用者可在自身会话明确采用公开固定内容；这不等于原维护者的发布批准已核验。私人批准索引无法通过当前可信渠道核对时，标为未核实，可以读取、讨论和准备；不得仅凭 approved 字段宣称正式生效或执行依赖该批准的发布、迁移等动作。不得为核验要求公开私人审批原文。

完整读取、同 pin 缓存、回复前检查和读取失败处理统一遵循 [core 总纲与第12节](../core/PROTOCOL.md)。实际采用的完整正文与来源须可区分；摘要、搜索片段不算全文。通用开场只用[新需求口令](../templates/new-requirement-opener.md)，不在各客户端复制另一套协作规则。

## 主助手核验正式发布时的目标行为

1. 及时响应用户；启动项目、批准变更和发布前核对适用 pin，日常对话不逐句重复核验。
2. 将 manifest 和 core/PROTOCOL.md 固定在同一不可变提交读取。
3. 校验 protocol_id、version、status、原始字节 SHA-256，以及经过认证渠道的批准引用。不能只相信仓库文字。
4. 必要时在获准任务上下文保留适用版本、提交与正文哈希；仅加载指定项目，不为日常沟通增加工程表单。
5. 发布无变化时复用已校验缓存。查询失败时明确标注“最后已核验版本，未证明最新”，并处理撤销和权限不确定性。
6. 新版本先做影响评估；原审批范围不自动扩大。

## 可选工程标准加载

只有项目明确采用工程标准时，读取该工程版本所选固定发布快照的独立清单、正文和其列出的配套材料。交叉核验 standard_id、正文版本、状态、审批证据、正文及配套文件原始字节、core 依赖和目录固定来源；工程 1.0.0 按原快照根清单交叉核验；工程 1.1.0 按自身 material_files 核验，core 依赖及根清单另从固定 07fffb46a1946392d63614dd82e698cef8f0cec0 读取。旧根清单材料摘要不校验新工程字节。

根清单的 version 只表示当前快照 core，不是仓库总版本。旧接入器仅验证原 core 字段，不能声称已支持新增 files、独立标准与依赖读取契约；人工读取约定不等于机器 schema 或客户端能力已经实现。具体契约见 [发布约定](../releases/README.md)。

新版本发现、采用、配置部署分别处理；固定历史快照不能证明当前权限或未撤销。读不到依赖时暂停相关动作，不擅自降级到 main、旧缓存或未批准版本。

Codex 专用偏好与安装前检查见 [Codex 说明](codex/README.md)，具体值仅在[两行模板](codex/config.toml.example)维护；不适用于其他模型，不扩大工具权限。事件、运行、配置及自动加载须各自实测。

## 可选有限批次

以下历史有限批次技术约定仅供明确选用者使用，不作为当前执行者默认工作流。统一目标文字、启动前检查与 Q0 契约唯一维护于工程正文第十二、十三节。项目明确采用后只增薄入口；本机加载与每次运行前检查单独验证。客户端差异见 [Codex](codex/README.md) 与 [DSH](dsh/README.md)，不能相互套用工具参数、权限或终态限制。适配说明不授权安装、运行、自动抢单或未来任务等待。
